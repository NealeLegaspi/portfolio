# Neale D. Legaspi — IT Portfolio

A responsive, single-page personal portfolio built with HTML5, CSS3, JavaScript, Bootstrap 5.3.3, and Bootstrap Icons.

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a modern browser.
3. An internet connection is used for Bootstrap, Bootstrap Icons, and Google Fonts CDN assets.

## Customize before publishing
- Replace the initials-based profile placeholder in `index.html` with a professional photo if desired.
- Check contact details and all dates before sharing publicly.
- Add real project screenshots and GitHub/repository links where available. The current project visuals are CSS illustrations, not screenshots of the actual applications.
- The resume and four certificate PDFs are in `assets/`.
- Do not publish private student, employer, or system data in project screenshots.

## Publish
You can host this static site using GitHub Pages, Netlify, or another static web host. Upload the contents of this folder, preserving the `assets/` directory structure.
